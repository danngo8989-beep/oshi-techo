# 推し活手帳 💖

推しの「予定」と「お金」をまとめて管理できる無料の推し活アプリ（PWA）です。

## できること

- 💖 **推しの登録** — 複数の推しに対応。推しカラーで色分け、「推して◯日目」を自動カウント
- 💰 **支出の記録と予算管理** — カテゴリ別・推し別に集計。月の予算を決めると「あといくら使えるか」が見える
- 📅 **現場カレンダー** — ライブ・リリイベ・配信の予定を登録すると「あと◯日」のカウントダウン表示
- ✈️ **遠征費の見積もり** — 交通費・宿泊費・チケット・グッズ予算をイベント単位で合算
- 🎂 **記念日カウントダウン** — 誕生日などの記念日を毎年自動でお知らせ

## 特徴

- インストール不要でブラウザからすぐ使える（ホーム画面に追加すればアプリとして動作）
- オフラインでも動作（Service Worker）
- データは端末内（localStorage）にのみ保存。外部送信は一切ありません

## 技術構成

ビルド不要の素のPWA: HTML + CSS + JavaScript + Web App Manifest + Service Worker
